# PRODUCT REQUIREMENTS & DATA DICTIONARY

## Project definition

**Nama:** Crisbar Raw Material Waste Intelligence Dashboard  
**Problem:** Waste data bersifat transaksional, panjang, dan belum langsung menghasilkan ringkasan prioritas evaluasi dengan aturan konsisten.  
**Tujuan:** Mempermudah inspeksi biaya waste, alasan, SKU, lokasi, tren tanggal, dan kualitas data; tanpa membuat kesimpulan operasional di luar isi CSV.  
**Tools:** IBM Bob untuk proses pengembangan, HTML/CSS/JavaScript murni untuk output.

## User stories

- **SCM HO:** "Saya ingin melihat total biaya waste, alasan dominan, produk utama, serta detail transaksinya agar investigasi lebih cepat."
- **Area Manager:** "Saya ingin mengisolasi outlet dari Kantor, CK, dan DC agar ranking outlet tidak tercampur karakteristik produksi."
- **Finance:** "Saya ingin tahu apakah biaya N/A dan dokumen Batal mempengaruhi angka yang disajikan."
- **QA/CK/DC:** "Saya ingin mengidentifikasi alasan Rusak, Kadaluarsa, dan Tidak terjual serta meninjau catatan transaksi sebelum menyimpulkan akar masalah."
